# CATIA V5 + Codex на Windows — один агент

Один Codex читает чертёж и выделение, составляет план, сам вызывает инструменты
CATIA и проверяет результат. Субагенты и cad_executor больше не требуются.
Отдельного платного AI API в Python-сервере нет.

## Установка одним файлом

Полная сборка `CATIA-AI-Setup.exe` устанавливает всё в профиль Windows текущего
пользователя: Codex CLI, автономный Python 3.13.3, CATIA MCP и зависимости,
включая PDF/изображения. Отдельно искать Node, ставить Python, Git или запускать
PowerShell не нужно. Установщик не требует прав администратора.

Чтобы скачать сборку из GitHub: открой **Actions → Build CATIA AI Windows
installer → Run workflow**, дождись завершения, открой завершённый запуск и
скачай artifact `CATIA-AI-Windows-Installer`. Распакуй artifact, запусти
`CATIA-AI-Setup.exe`, оставь выбранный ярлык и запусти **CATIA AI** после
установки. При первом запуске войди в Codex через ChatGPT. Для сборки нужен
Windows x64; она пока создаётся вручную из GitHub Actions и не является
постоянной кнопкой Download на странице репозитория.

Установщик содержит автономный Codex `codex.exe`; поэтому Node в этой сборке
не нужен. Python и пакет MCP лежат рядом с приложением в его пользовательской
папке и не меняют системный PATH. Архив Codex проверяется по SHA-256 из
официального GitHub release. Обновление — установить новую сборку поверх старой;
пользовательские настройки Codex не перезаписываются.

## Установка из исходного ZIP

Для исходного ZIP нужны Windows, Python 3.10+, CATIA V5 и разрешённый доступ к PyPI/npm.
Git, администраторские права и изменение ExecutionPolicy не нужны.

1. Скачай и полностью распакуй ZIP. Открой папку с INSTALL.cmd.
2. При обновлении сохрани старую рабочую папку как резервную копию. Можно заменить
   только файлы проекта в прежней папке, сохранив Windows .venv и .local.
   Не переноси .venv или .local с Mac и не запускай две копии одновременно.
3. Дважды нажми INSTALL.cmd. Дождись Setup complete и Exit code: 0.
4. Открой CATIA. Старый чат Codex заверши.
5. Дважды нажми START_CATIA_AI.cmd — либо START_WITH_DRAWING.cmd для выбора чертежа.
   При необходимости войди в Codex и доверь только папку этого проекта.

INSTALL переиспользует Node/Codex, в том числе сохранённые пути в
.local/windows-runtime.json, %LOCALAPPDATA%/codex-cli и Node ZIP в Downloads.
Если Node не найден, выбери node.exe из полностью извлечённого официального
[Node.js LTS ZIP](https://nodejs.org/en/download). Node автоматически не скачивается.
Если Codex отсутствует, npm устанавливает его локально в .local/codex.
Без Node допустим уже установленный самостоятельный codex.exe.

Установка добавляет зависимости для PDF/изображений, проверяет пакет и MCP.
setup_codex.ps1 оставлен только как обёртка над INSTALL.cmd; если PowerShell его
блокирует, используй .cmd. Никакого Bypass.

## Что изменилось в подключении

START передаёт Codex настройки через параметры только текущего запуска:

- agents.enabled=false — без создания субагентов;
- catia-v5 — полный сервер через абсолютный путь к Python проекта (venv в
  исходном ZIP или встроенный Python в полной установке);
- catia-v5-inspect — отключён в этой сессии, с полным определением транспорта.

Основной .codex/config.toml, личные настройки Codex и старые файлы ролей не
перезаписываются. Прежняя глобальная регистрация inspect остаётся на диске, но
в запущенной через START сессии отключена. Другие MCP-настройки не меняются.
Используется документированный механизм
[CLI overrides](https://learn.chatgpt.com/docs/config-file/config-advanced).
Не запускай просто codex и не возобновляй старый инспекционный чат: они могут
использовать прежние настройки. Системный PATH тоже не меняется.

В новом чате /mcp должен показывать включённый catia-v5 с 81 инструментом.
Стартовый запрос проверяет инструменты САМОГО главного агента: catia_new_part,
catia_pad, catia_get_model_state, catia_get_selection, catia_screenshot.
Эта проверка ничего не строит. После PASS можно дать конкретную задачу.

## Чертёж: фото или PDF

START_WITH_DRAWING.cmd открывает окно выбора PNG, JPEG или PDF. Все страницы PDF
рендерятся локально в PNG и прикладываются к начальному сообщению Codex по порядку.
Исходный файл не меняется. Копии находятся в .local/drawings; это локальные файлы,
но при запуске они передаются Codex как вложения — выбирай только разрешённые для
передачи чертежи.

Лимиты: 50 MB, PDF от 1 до 12 страниц; 144 dpi с ограничением 4096 пикселей на
сторону. Если страниц больше, весь документ отклоняется, а не обрезается молча.
Для мелких размеров приложи крупный фрагмент. HEIC сначала экспортируй в PNG/JPEG.
PDF с паролем нужно заранее открыть и экспортировать разрешённую незашифрованную
копию. Фото детали без размеров не позволяет восстановить точную геометрию.

Картинку также можно вставить в интерактивный Codex; см.
[официальную инструкцию по изображениям](https://learn.chatgpt.com/docs/image-inputs).
Выбор файла сам по себе НЕ разрешает построение. После разбора чертежа напиши:

> Создай НОВУЮ деталь — кронштейн по приложенному чертежу; размеры, которых не
> видно, сначала уточни. Работай сам, без субагентов. Другие документы не меняй.
> После построения обнови модель, проверь размеры и покажи скриншот. Не сохраняй.

Если размеры и разрешение уже даны, агент должен выполнять задачу, а не только
останавливаться на плане. Но полностью автоматическое построение произвольной
детали по любому фото не гарантируется.

## Первый безопасный тест без чертежа

После PASS в START_CATIA_AI.cmd:

> Создай одну НОВУЮ несохранённую CATPart. В ней построй прямоугольник 40 x 20 мм
> на плоскости XY и Pad толщиной 5 мм. Сам выполни построение через MCP, без
> субагентов и Python COM-скриптов. Другие документы не меняй. Обнови модель,
> проверь размеры 40 x 20 x 5 мм по доступным данным и покажи скриншот.
> Не сохраняй и не закрывай документы. При ошибке остановись и сообщи её.

Правила AGENTS.md: состояние и выделение → одно действие → update → состояние
и измеримые размеры → скриншот → проверка. Самопроверка не равна независимой
экспертизе. Во время построения не переключай активный документ и не запускай
другую CAD-автоматизацию.

## Выделение и ограничения

Можно спросить: «Что открыто?», «Что я выделил?», «Какой размер у этой фичи?».
Чтение выделения и модели сохранено; обновление выбранной поддерживаемой
фичи/эскиза работает с текущим COM-объектом, не с сохранённым ID.

Точное адресование выбранной грани/ребра для Fillet, Chamfer, Hole, Sketch
пока не реализовано и не подтверждено. Имена и индексы не являются стабильными
ID. Скриншот возвращает изображение MCP и путь; разрешение определяется окном
CATIA, параметры width/height не принимаются.

## Диагностика

DIAGNOSE.cmd проверяет эффективные настройки ЭТОГО запуска и реальный stdio
discovery: 81 полный / 13 инспекционных инструментов. Инспекционный процесс
проверяется отдельно, но в интерактивной одноагентной сессии он отключён.
Ни один инструмент CATIA при диагностике не вызывается.

Логи: .local/diagnostics.log, .local/setup.log, .local/start.log.
Просмотри локальные пути перед отправкой. MCP JSON с секретами и чат не логируются.
Если диагностика PASS, но в чате нет инструментов, пришли ошибку запуска MCP
и результат /mcp — не повторяй установку бесконечно.

Windows .cmd, отображение вложений, доступ инструментов внутри нового чата,
COM-построение и размеры требуют живой проверки. Offline-тесты этого не доказывают.
Если университет блокирует запуск программ или загрузку пакетов, обратись к IT.
