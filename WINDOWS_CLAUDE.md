# CATIA AI: Codex и Claude Code на Windows

Один Python MCP-сервер, два способа вести диалог. В сервере нет отдельного
платного AI API. Вход в OpenAI и Anthropic независимый; доступ Codex не даёт
автоматически доступ к Claude. Это интеграция с **Claude Code**, не настройка
Claude Desktop.

## Запуск из ZIP

1. Распакуй проект в обычную локальную папку. Закрой старые CAD-сеансы агентов.
2. Дважды нажми `INSTALL.cmd`. Он устанавливает общую `.venv`, при необходимости
   скачивает Python и Node, затем Codex и Claude Code в `.local/codex` и
   `.local/claude`. Повторный запуск использует уже найденные программы.
3. Открой CATIA. Нажми `START_AI.cmd` и выбери **1 — Codex** или **2 — Claude**.
   Войди в соответствующий аккаунт, если клиент попросит. Вход не автоматизируется.
4. В Claude введи `/mcp`: `catia-v5` должен подключиться. Попроси найти доступные
   `catia_new_part`, `catia_pad`, `catia_get_model_state`, `catia_get_selection`,
   `catia_screenshot` без их вызова. Затем можно читать состояние и работать.

Если нужен только один клиент, в PowerShell из папки проекта:

```powershell
.\INSTALL.cmd --client codex
```

Или запусти `INSTALL_CLAUDE.cmd` для Claude. При сетевой ошибке установки второго
клиента первый не удаляется. Установка не меняет ExecutionPolicy, системный PATH,
не требует Git или администратора и не обходит ограничения университета.

## Кнопки

| Файл | Действие |
| --- | --- |
| `START_AI.cmd` | Выбор одного клиента |
| `START_CATIA_AI.cmd` | Codex |
| `START_CLAUDE_AI.cmd` | Claude Code |
| `START_WITH_DRAWING.cmd` | Codex с PDF/изображением |
| `START_CLAUDE_WITH_DRAWING.cmd` | Claude с выбором PDF/изображения |
| `DIAGNOSE.cmd` | Проверка Codex и MCP transport |
| `DIAGNOSE_CLAUDE.cmd` | Проверка Claude CLI, session config и MCP transport |

PDF преобразуется в упорядоченные PNG. Claude получает файл со списком страниц
и указание открыть каждое изображение. Astra → Luna остаётся функцией Codex;
модели Claude автоматически не переключаются. Размеры, которых не видно,
ассистент должен уточнять.

Claude запускается с `--mcp-config .local/claude-mcp.json --strict-mcp-config`:
только полный CATIA MCP для этого сеанса, с абсолютным Python из проекта.
`AGENTS.md` добавляется к инструкциям, `CLAUDE.md` описывает рабочий процесс.
Глобальные настройки Claude/Codex и `.codex/config.toml` не переписываются.
Обычные разрешения Claude сохраняются; launcher не включает bypassPermissions.
Managed settings организации могут запретить MCP даже при правильном конфиге.

**Не запускай два клиента на запись в одну CATIA одновременно.** Между ними
нет общей блокировки COM. Для перехода закончи текущую операцию, закрой первый
сеанс, открой другой и заново прочитай модель/выделение. Диалог автоматически
между аккаунтами не переносится.

## Безопасный первый тест

В чистой CATIA попроси: «Создай новую несохранённую сборку TestAssembly, затем
добавь в неё новую деталь. Прочитай дерево и ничего не сохраняй». Для Drawing:
«Создай новый несохранённый чертёж. На первом листе создай таблицу 2×3 в позиции
(20, 30) мм, строки высотой 8 мм и столбцы шириной 30 мм. Впиши Part в ячейку
(1, 1), прочитай её обратно. Ничего не сохраняй».

Затем проверь точные сборочные связи на тестовых компонентах, формат/проекцию
листа, положение текста, таблицы, ассоциативные виды и изменения размеров.
Список новых операций и Windows-проверок: [ASSEMBLY_DRAWING.md](ASSEMBLY_DRAWING.md).

## Существующий EXE

Полный установщик продолжает содержать Python/MCP и Codex. В новой сборке
есть ярлыки и необязательный шаг скачивания Claude через `INSTALL_CLAUDE.cmd`;
сам бинарник Claude в payload не включён. Для этого шага нужен интернет, Node
при необходимости скачивается автоматически. Старые EXE не меняются от правки
исходников: нужен новый Windows build. На Mac эта сборка и запуск не проверены.

Реализация следует [установке Claude Code](https://code.claude.com/docs/en/setup)
и [CLI flags](https://code.claude.com/docs/en/cli-reference). Эти документы
описывают npm-установку и session MCP config; они не подтверждают работоспособность
CATIA COM на конкретном университетском компьютере.
